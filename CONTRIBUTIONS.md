# Вклад участников

Каждый участник отвечает за одну сквозную цепочку `T → SR → D → будущая проверка` приоритетного набора и за часть общей модели продукта. Документы: [паспорт](PROJECT.md), [требования](docs/security-requirements.md), [модель угроз](docs/threat-model.md), [проектные решения](docs/design-decisions.md).

Подготовлены [выступление](docs/ek1-defense.md), команды macOS/Linux в [README](README.md) и [протокол проверки каркаса](docs/ek1-verification.md). Это отдельное изменение существующей концепции; авторство исходного кода каркаса сохраняется за его историей.

Содержательная проверка M3 на момент подготовки не подтверждена. До принятия изменений участник проверяет материал и самостоятельно объясняет выбранные решения.
